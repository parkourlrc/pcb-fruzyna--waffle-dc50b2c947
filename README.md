# Waffle Keyboard

Waffle is a 6x5 ortholinear keyboard which uses TRRS connectors to form a split keyboard when two are connected.
It is designed to be used with an [Elite-C](https://keeb.io/products/elite-c-low-profile-version-usb-c-pro-micro-replacement-atmega32u4) or [Elite-Pi](https://keeb.io/products/elite-pi-usb-c-pro-micro-replacement-rp2040) microcontroller.
There are currently two revisions, descriptions are available on the [releases page](https://github.com/fruzyna/keyboard/releases).

This keyboard is designed in KiCad.
Footprints are based off of the following libraries:
- https://github.com/keebio/keebio-components
- https://github.com/keebio/Keebio-Parts.pretty
- https://github.com/daprice/keyswitches.pretty
